# Minigame 1
## Devlog
I think of Unity like a movie set. A Component is like a tool or ability given to an actor or object, such as a character’s movement system. A GameObject is like an actor or prop on the set, because it can have different Components that control how it looks and behaves. A Scene is like the whole movie set where all the actors and props are placed together. In my level, the PlayerCapsule is a GameObject with a FirstPersonController Component that controls the player’s movement, while the platforms, coins, and spikes are other GameObjects in the Scene. Changing the Component changes how a GameObject behaves, while moving or adding GameObjects changes the Scene itself. This helped me understand that Components control the details, GameObjects are the objects that use those details, and the Scene brings everything together into a playable level.
